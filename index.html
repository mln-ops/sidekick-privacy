随行 Sidekick 隐私政策

生效日期：[ 2026-09-27]
开发者：[mln-ops]（联系邮箱：[malina@smart-core.cn]）

1. 我们不收集任何个人数据

本插件没有自有服务器，不存在任何向我们传输或存储用户数据的行为。

2. API Key 的存储

用户自行配置的第三方大模型 API Key 仅保存在用户浏览器本地的 chrome.storage.local 中，不会上传到任何远程服务器，卸载插件即彻底删除。

3. 第三方服务

插件仅作为客户端，代表用户直接调用用户在设置中自行配置的大模型 API（如 DeepSeek、Kimi、通义千问、智谱等 OpenAI 兼容接口）。请求内容（选中的文字、网页正文、对话内容）仅发送到用户自己配置的模型服务商，受其服务商隐私政策约束，与本插件无关。

4. 数据内容

插件可读取用户当前浏览网页的正文内容，用于实现「网页总结」「划词解释」功能；该内容仅在用户主动触发相关功能时发送至用户配置的模型 API，不会被收集、存储或用于任何其他目的。

5. 数据共享与出售

我们不向任何第三方出售、共享、转让用户数据。

6. 儿童隐私

本插件不面向 14 周岁以下儿童，不收集任何年龄信息。

7. 政策变更

如本政策更新，将在插件商店列表页同步更新。
